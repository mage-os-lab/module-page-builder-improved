## [Unreleased]

First release of `mage-os/module-page-builder-improved`, which replaces the modules' former packages
(`mage-os/module-page-builder-components`, `-components-examples`, `-ui`, `-layout`). What each module adds:

- **MageOS_PageBuilderComponents**: Page Builder content types declared with `#[PageBuilderComponent]` and field
  attributes on a block class. [Details](src/PageBuilderComponents/CHANGELOG.md).
- **MageOS_PageBuilderComponentsExamples**: Hero, Cards, USP List, Image & Text and Call to Action components,
  with a CSS framework agnostic stylesheet. [Details](src/PageBuilderComponentsExamples/CHANGELOG.md).
- **MageOS_PageBuilderLayout**: layout settings per viewport (gaps, columns per line, flex and grid layouts) and a
  Tablet view on the stage. [Details](src/PageBuilderLayout/CHANGELOG.md).
- **MageOS_PageBuilderUi**: a fresh new editor UI, with a collapsible panel, a list view and the edit form as a
  tabbed sidebar. [Details](src/PageBuilderUi/CHANGELOG.md).
