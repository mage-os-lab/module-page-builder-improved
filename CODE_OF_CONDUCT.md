# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. The full text (pledge, standards, enforcement guidelines) lives at that URL. Please read it
before contributing.

## Reporting

Report abusive, harassing or otherwise unacceptable behavior privately to a maintainer of this repository
(contact details on their GitHub profile), or to the [Mage-OS](https://mage-os.org) team.
All complaints are reviewed and investigated promptly and fairly, and the reporter's privacy is respected.

This Code of Conduct is adapted from the [Contributor Covenant](https://www.contributor-covenant.org), version 2.1.
